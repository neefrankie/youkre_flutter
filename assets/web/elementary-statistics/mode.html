如何找出众数

众数(mode 或 modal value)是出现次数最多的那个数。

例子

在 [6, 3, 9, 6, 6, 5, 9, 3] 中，6 出现的次数最多，所以众数是 6。

数字 出现次数
3 ✓ ✓
5 ✓
6 ✅ ✅ ✅
9 ✓ ✓

怎么找众数？

找众数时，最好先把数字按顺序排列，这样更容易统计每个数出现的次数。出现次数最多的数就是众数。

例子

原始数据：

3, 7, 5, 13, 20, 23, 39, 23, 40, 23, 14, 12, 56, 23, 29

排序后：

3, 5, 7, 12, 13, 14, 20, 23, 23, 23, 23, 29, 39, 40, 56

可以清楚地看出哪个数出现得最多。在这个例子中，众数是 23。

例子：[19, 8, 29, 35, 19, 28, 15]

排序后：[8, 15, 19, 19, 28, 29, 35]

19 出现了两次，其他都只出现一次，所以众数是 19。

小窍门：记住 “众数”就是“最多”的那个

可能有多个众数

一组数据中可能会有不止一个众数。

例子：[1, 3, 3, 3, 4, 4, 6, 6, 6, 9]

3 出现了 3 次，6 也出现了 3 次，所以这组数有两个众数：3 和 6

这种情况叫做 双众数（bimodal）。如果有两个以上众数，就叫做 多众数（multimodal）。

分组来找众数

有时候所有数值出现的次数一样，这时直接找众数没意义。我们可以对数据进行分组，看哪一组出现得最多。

例子：[4, 7, 11, 16, 20, 22, 25, 26, 33]

每个数都只出现一次，试着分组，每组间隔为 10：

  • 0–9：2 个数（4 和 7）
  • 10–19：2 个数（11 和 16）
  • 20–29：4 个数（20、22、25、26）
  • 30–39：1 个数（33）

“20–29”这一组出现最多，可以选这个区间中间的数 25 作为众数。

也可以用不同的分组方式，得到不同的结果。

例子：装满一个托盘要多久？

餐厅记录了每次装满一个托盘所需的时间（单位：分钟）：

[35, 36, 32, 42, 58, 56, 35, 39, 46, 47, 34, 37]

因为有时遇到休息或午餐时间，平均值不具代表性。

按每组 5 分钟来分组：

  • 30–34：2 次
  • 35–39：5 次
  • 40–44：1 次
  • 45–49：2 次
  • 50–54：0 次
  • 54–59：2 次

“35–39”这一组出现最多，说明通常需要大约 37 分钟来装满一个托盘。
